# BodyParts3D import path (optional validated anatomy source)

The bundled `assets/models/anatomy/` pack is an **illustrative educational mesh pack generated for this project**. It is not BodyParts3D and is not suitable for diagnosis or clinical measurement.

For a validated external anatomy mesh source, BodyParts3D publishes polygon meshes in Wavefront OBJ format. The official LSDB Archive lists a 99% polygon-reduced PART-OF package and an IS-A package. BodyParts3D is licensed under **Creative Commons Attribution 4.0 International**, and redistribution requires attribution.

Required attribution when BodyParts3D data is actually imported/distributed:

`BodyParts3D, © The Database Center for Life Science licensed under CC Attribution 4.0 International`

Official pages:
- https://dbarchive.biosciencedbc.jp/en/bodyparts3d/download.html
- https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html

The current build environment could not retrieve the large archive directly, so **no BodyParts3D mesh bytes are bundled in this checkpoint**. Do not claim otherwise.
