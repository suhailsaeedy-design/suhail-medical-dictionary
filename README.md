# Suhail Medical Dictionary v9.0

Premium responsive redesign for GitHub Pages. Default theme is Light.

Production deployment imports the NLM MeSH 2026 dataset through GitHub Actions.

Key experience: 3D term visuals, rotating detail artwork, mobile slide-out navigation, compact mobile term cards, multiple full themes, Google account login, AI Study workspace, PDF/print tools, offline/PWA support, and an in-app About page for Suhail Saeedy.

AI Study is presented as a separate study feature; the website itself is described as a medical learning platform.


## v9.0 design
The v8 UI follows the approved luminous medical reference direction: a light default workspace, optional deep-blue neon themes, glass panels, animated 3D term visuals, responsive mobile drawer/bottom-sheet interactions, compact mobile cards, and cursor/touch liquid micro-interactions.
