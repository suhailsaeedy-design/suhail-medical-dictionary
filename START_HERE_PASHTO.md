# له دې ځایه شروع کړه — Suhail Medical Dictionary v10.0

دا ZIP Extract کړه. بیا د Extract شوي `Suhail_Medical_Dictionary_v10.0_Complete_Reference_Project` فولډر **دننه ټول files او folders** خپل GitHub repository `suhail-medical-dictionary` ته واچوه.

مهم فولډرونه لکه `.github`, `assets`, `data`, `scripts`, `supabase` او فایلونه لکه `index.html`, `app.html`, `sw.js` باید ټول پورته شي.

GitHub کې:

1. `Settings → Pages` ته لاړ شه.
2. Source د **GitHub Actions** وټاکه.
3. `Actions` ته لاړ شه او `Build and deploy Suhail Medical Dictionary` workflow ته انتظار وکړه.
4. چې workflow شین/Success شو، خپل GitHub Pages ویب سایټ په `Ctrl + F5` سره Refresh کړه.

Google Client Secret هېڅکله GitHub ته مه پورته کوه. پروژه یوازې د Supabase عامه publishable key لري.
