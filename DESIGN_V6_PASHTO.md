# Suhail Medical Dictionary v6.0 — Premium 3D UI

دا نسخه د تایید شوي reference عکس مطابق بیا ډیزاین شوې ده:

- ثابت Left Sidebar
- Premium blue/white medical dashboard
- 3D-style local medical visuals د term cards او detail panel لپاره
- Search bar، category chips، language، themes او account controls
- د term لوی detail panel، تلفظ، مترادف، MeSH ID، AI Study او Selected action
- PDF/Print/Offline tools خوندي پاتې دي
- Mobile/Tablet responsive layout

## د عکسونو په اړه
د 31,000+ MeSH terms لپاره په ZIP کې 31,000 جدا حقیقي عکسونه اچول د static/offline package حجم ډېر لوی کوي او د copyright/accuracy ستونزې هم جوړوي. v6 د term نوم، category او medical keyword له مخې مناسب local 3D-style medical visual ټاکي. ټول visuals offline کار کوي.

## GitHub ته upload
په موجود repository فولډر کې ټول زاړه فایلونه لرې کړئ، خو `.git` مه حذف کوئ. د ZIP دننه ټول فایلونه paste، بیا GitHub Desktop کې Commit او Push وکړئ.
