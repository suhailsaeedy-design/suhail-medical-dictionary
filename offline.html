Offline Packs & Updates

Keep your core medical terminology available when the internet is limited.

Use the Dictionary page while online and choose Download offline pack. The Progressive Web App stores the index, category packs, interface files, and local study resources on this device.

1

Download once

Open the Dictionary online and press “Download offline pack”. Progress is shown while the category data is cached.

2

Study offline

Search downloaded terms, browse saved categories, use device pronunciation, selections, bookmarks, and browser printing without internet.

3

Reconnect for cloud features

Google sign-in refresh, private chat sync, new AI responses, and uncached translations require an internet connection.

↻

Automatic updates

When the device reconnects, the app checks for a newly deployed GitHub Pages release and updates the cached application files.

⌂

Install on phone

On iPhone/iPad use Share → Add to Home Screen. Supported desktop and Android browsers can use the Install app option.

◉

Storage control

The complete production dictionary is large. You can remove downloaded offline data at any time and download it again later.
