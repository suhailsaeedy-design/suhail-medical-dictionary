Offline use & automatic updates

First download: open the Dictionary while online and press “Download complete offline dictionary.” The app stores the current search index, category packs, and supported export resources in the browser's app cache.

After that: search, categories, definitions already included in the downloaded packs, selection, pronunciation provided by the device, and browser printing remain usable without internet. Cloud login, new AI responses, and new AI translations need internet.

Installation: on supported browsers use the Install button. On iPhone/iPad use the browser Share menu and choose Add to Home Screen.

Updates: the app checks for new releases when opened, when it returns to the foreground, when internet reconnects, and periodically while open. A newly deployed release activates automatically and reloads the app. A device that is fully offline keeps its last downloaded version until it reconnects.

Storage: the full MeSH build can be substantial. The app shows download progress and uses multiple data chunks so individual hosting assets remain within free-host limits. Offline data can be removed at any time.
