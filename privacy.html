Privacy & data

Privacy Notice

A plain-language summary of what Suhail Medical Dictionary stores, how study data is separated, and how offline and AI features handle information.

Back to dictionaryTerms

What is stored

In Zero-Cost Mode, your local account identifier, study-chat history and activity events stay on this device. If you intentionally enable optional cloud features, cloud account and chat data may be stored by the configured service. Core Dictionary, Anatomy, Clinical Reference and local Study Engine do not require cloud storage.

User separation

Local-only accounts keep study data on the same device. If optional Supabase cloud storage is enabled, database row-level security separates user chats and account records, and the optional AI Worker verifies the signed-in user before cloud chat access.

Owner access

The owner can see system analytics such as user counts and activity. Stored chat content is reviewable only while the user has explicitly enabled owner-review consent.

Medical privacy

Avoid entering unnecessary personally identifying health information. AI chat is an educational study feature, not a confidential clinical service.

Offline data

Downloaded dictionary packs and app caches are stored locally on the device and can be removed from Offline Packs.

Medical content & sources

Study-engine output, optional cloud AI output and translations can be wrong and should be checked against trusted references and instructors. Bundled content identifies its own project dataset and does not claim endorsement by external medical publishers or services.

Educational notice

This project supports study and reference. It is not a medical diagnosis, emergency, or treatment service.
