Privacy Notice

What is stored: when cloud features are enabled, the service stores your account identifier, chat history, selected-term context sent with a chat, and basic activity events needed for account/system administration. Dictionary use itself can work without signing in.

User separation: database row-level security limits ordinary users to their own chats and account records. The AI Worker also verifies that a requested chat belongs to the signed-in user before reading or writing it.

Owner access: the owner can see system analytics such as user counts and activity. The owner can read a user's stored chat content only while that user has explicitly enabled the “Allow owner to review my chat content” setting. Users can turn that consent off from the Dictionary page.

Medical privacy: avoid entering unnecessary personally identifying health information. AI chat is an educational study feature, not a confidential clinical service.

Offline data: downloaded dictionary packs and app caches are stored locally on the device. They can be removed with the “Remove offline data” control.

Medical content: AI output and AI-assisted translations can be wrong and should be checked against trusted references and instructors. This site is not a diagnosis, emergency, or treatment service.

Source attribution: where NLM MeSH data is distributed, the site identifies the data version and acknowledges the U.S. National Library of Medicine as the source. NLM does not endorse this project.
